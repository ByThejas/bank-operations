# 🏧 Mini ATM — Java

A simple console-based ATM simulator built in Java as a beginner project to practice core Java programming concepts.

## 📌 About

This project simulates basic ATM operations through a command-line interface. The goal is to practice combining Java fundamentals into a small working application rather than just learning individual concepts.

## ✨ Features

* 💰 Check current balance
* ➕ Deposit money
* ➖ Withdraw money
* 🚫 Prevent withdrawal when the balance is insufficient
* 🔄 Interactive ATM menu
* 📜 Transaction history
* 📦 Store transaction details using arrays

## 🧠 Concepts Practiced

This project currently focuses on:

* Variables and data types
* `if-else` statements
* `switch` statements
* `do-while` loops
* Methods
* Arrays
* Array indexing
* User input using `Scanner`
* Basic class and object usage
* Managing data across multiple methods

## 🛠️ Technologies

* **Language:** Java
* **IDE:** IntelliJ IDEA
* **Type:** Console Application

## 🚀 How It Works

When the program starts, the user is presented with an ATM menu:

```text
===== MINI ATM =====

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Transaction History
5. Exit
```

The user selects an option, performs the required operation, and is returned to the menu until they choose **Exit**.
